# Equipment Management

This document is packaged with the plugin manifest for marketplace display.

## Overview

Official source plugin for equipment registry and maintenance record management

## Highlights

- Equipment registry with tenant-unique codes and dictionary-driven types/statuses.
- Maintenance records for upkeep, repair, and inspection history with date-range search.
- Reference protection: equipment still referenced by maintenance records cannot be deleted.

## Usage

1. Install and enable `Equipment Management` in plugin management.
2. Open `Equipment` under the content directory to maintain the registry.
3. Open `Maintenance Records` to log upkeep and repair history.
