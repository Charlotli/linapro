# Book Management

This document is packaged with the plugin manifest for marketplace display.

## Overview

Official source plugin for book registry and borrow management

## Highlights

- Book registry with tenant-unique ISBN and dictionary-driven categories/statuses.
- Borrow management: lending decrements available copies, returning increments them, linked in one transaction to prevent overselling.
- Reference protection: books still referenced by borrow records cannot be deleted.

## Usage

1. Install and enable `Book Management` in plugin management.
2. Open `Books` under the content directory to maintain the registry.
3. Open `Borrow Records` to log lending and returns.
