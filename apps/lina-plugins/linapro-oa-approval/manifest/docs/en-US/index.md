# OA Approval

This document is packaged with the plugin manifest for marketplace display. Adding document resources does not change plugin runtime behavior.

## Overview

Official source plugin for configurable approval flows covering fund requests, write-offs, and reimbursements

## Document Navigation

- [Configuration](configuration.md)
- [Changelog](changelog.md)

## Highlights

- Configurable flows: ordered approver nodes per fund-request, write-off, and reimbursement type.
- Complete actions: approve, reject, reply, append approver, and withdraw with frozen node snapshots.
- Proactive notifications: submissions, advances, rejections, appends, and withdrawals reach related users.

## Use Cases

- Internal fund, write-off, and reimbursement approvals for churches and organizations.
- Scenarios that need custom approval chains and complete approval records.
