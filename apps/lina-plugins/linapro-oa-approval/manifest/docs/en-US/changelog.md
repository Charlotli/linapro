# Changelog

## v0.1.0

- Added approval-flow configuration: ordered approver nodes per fund-request, write-off, and reimbursement type with enable/disable.
- Added approval requests: submit with frozen node snapshots, approve, reject, reply, append approver, and withdraw.
- Added the approval timeline and participant visibility boundary.
- Added inbox notifications for submit, advance, reject, append, and withdraw.
- Added attachment URL management stored as a JSON address array with at most 10 items.
