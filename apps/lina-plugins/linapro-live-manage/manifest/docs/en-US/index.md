# Live Management

This document is packaged with the plugin manifest for marketplace display. Adding document resources does not change plugin runtime behavior.

## Overview

Official source plugin for live-room and live-content management

## Document Navigation

- [Configuration](configuration.md)
- [Changelog](changelog.md)

## Highlights

- Live-room management with tenant-unique codes, types, and statuses.
- Live-content maintenance covering push/play URLs, song lists, sermon info, and scripture.
- Tenant-aware usage scenarios.

## Use Cases

- Online live back-office operations for churches and organizations.
- Centralized maintenance of live rooms and per-event live content.

## Usage

1. Install and enable `Live Management` in plugin management.
2. Open `Live Rooms` under the content directory to maintain live rooms.
3. Open `Live Content` under the content directory to maintain each live event.
