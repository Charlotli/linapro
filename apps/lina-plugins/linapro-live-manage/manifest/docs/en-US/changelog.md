# Changelog

## v0.1.0

- Added live-room management: paged list, detail, create, update, batch delete, and bounded option candidates.
- Added live-content management: paged list, detail, create, update, and batch delete, covering push/play URLs, song lists, sermon info, and scripture.
- Added room-reference protection and availability validation; deleting a room referenced by live content is rejected.
- Added live enum dictionary seeds: room type, room status, live state, and visibility.
- Added live-room and live-content menus with query, add, edit, and remove button permissions.
