# 直播后台管理

本文档随插件清单打包，面向插件市场展示。新增文档资源不会改变插件运行时行为。

## 概述

提供直播间与直播内容维护的官方源码插件

## 文档导航

- [配置说明](configuration.md)
- [更新日志](changelog.md)

## 功能亮点

- 提供直播间管理，支持同租户唯一编码、类型与状态维护。
- 提供直播内容维护，覆盖推流/播放地址、歌单、讲道信息与经文。
- 支持租户感知使用场景。

## 适用场景

- 教会、团体等组织的线上直播后台运营。
- 需要集中维护直播间与每场直播内容的管理场景。

## 使用说明

1. 在插件管理中安装并启用`直播后台管理`。
2. 在`内容管理`目录下打开`直播间管理`维护直播间。
3. 在`内容管理`目录下打开`直播内容`维护每场直播的信息。
