# 直播开播日程日历订阅（ICS）

## Why

`add-live-h5-player`交付了观众端观播页后，会众参与直播仍依赖"自己记得时间"：预告页只在停留时展示开播日期，没有进入个人日历的路径。教会场景的聚会日程高度规律（主日崇拜、周间聚会），会众最自然的习惯是把聚会放进手机系统日历，由日历提醒代管"别忘了几点开播"。为每个房间提供一个稳定的订阅链接（ICS feed），会众在系统日历中订阅一次，该直播间未来的直播日程（含开播时间）自动同步——这是把"提醒"从插件责任转移给会众已有工具的最实用路径。

同时评估过并暂缓的备选：直播门户列表页（工程量大，可后续独立迭代）、PWA 离线缓存（依赖门户页，当前单房间页收益有限）、留言互动（需要治理审核成本）。

## What Changes

- 新增公开订阅接口（免登录、免权限点，挂既有公开路由分组）：
  - `GET /x/linapro-live-manage/api/v1/subscribe?roomCode=<roomCode>&tenantId=<tenantId>`：按直播间返回该房间近期公开直播的 ICS 日历流（`Content-Type: text/calendar`），默认窗口为未来 90 天 + 最近 7 天回放区间内的公开直播条目；租户上下文语义与`play`接口一致。
- ICS 条目语义：
  - 每场公开直播生成一个`VEVENT`：`UID`为直播记录稳定键（`linapro-live-<liveId>@linapro-live-manage`），`SUMMARY`为直播标题，`DTSTART/DTEND`取`liveDate`与起止时间（未开始直播取`startTime`/预计时长，已结束取实际起止时间戳），`DESCRIPTION`包含观播页直达链接。
  - 未开始且未录入`startTime`的直播以`liveDate`全天事件（`DTSTART;VALUE=DATE`）表达，避免编造时间。
- H5 观播页未开始（预告）态新增"添加到日历"操作：展示订阅链接按钮，点击后复制 ICS 订阅地址（并在支持的环境直接打开）；已开始/回放态不展示（日历提醒已无意义）。
- 管理端直播间列表操作列在"二维码"旁新增"日历订阅"动作：弹窗展示订阅链接与复制按钮，方便张贴到教会公告物料。
- 插件`apidoc`翻译资源同步新增订阅接口的`zh-CN`翻译（插件`i18n.enabled: true`）。

## Capabilities

### New Capabilities

- `live-manage` 能力扩展：直播日程日历订阅（公开 ICS 订阅接口 + H5 预告态入口 + 管理端订阅链接入口）。

### Modified Capabilities

- 无修改既有能力；`play`、`view`心跳、管理端既有接口均不变。

## Impact

- **数据库**：无变更（纯读接口，直接消费既有直播表数据）。
- **后端**：插件新增公开 ICS 输出逻辑（建议以`calendar`服务组件或`play`同包职责文件承载，实施时按复杂度判断）；复用播放选择的房间解析与公开可见性边界。
- **前端 H5**：预告态新增"添加到日历"按钮，随`go:embed`重新嵌入。
- **前端管理端**：直播间列表操作列新增一个动作与弹窗，复用二维码弹窗的交互形态。
- **测试**：ICS 输出正确性单元测试（时间窗口、全天事件、UID 稳定性、转义）、契约/E2E 断言（订阅头、H5 入口、管理端弹窗）。
- **i18n**：新增接口的`apidoc``zh-CN`翻译必须同步；H5 与管理端新增文案按既有机制维护。
