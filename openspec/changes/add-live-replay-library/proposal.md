# 直播往期回放库

## Why

当前观众端`play`接口对已结束直播只返回"最近一场"作为回放，更早的聚会回放观众完全看不到；管理端也没有以"回放"为视角的维护入口——哪些场次的回放可公开、哪些因隐私或质量原因需要下架，只能在直播内容列表里逐场翻找。本变更补齐"回放库"能力：观众在 H5 观播页可浏览并跳转观看该直播间全部往期回放，管理端可按场维护回放是否公开。

## What Changes

- **数据库**：直播表新增`replay_enabled`列（默认`true`），表示该场直播结束后是否提供公开回放；幂等`ALTER`进插件迭代 SQL，卸载 SQL 同步。
- **后端**：
  - 既有`play`接口的"已结束回放"回退逻辑增加`replay_enabled=true`过滤——被关闭回放的场次不再作为回放返回（进行中直播不受该开关影响）。
  - 新增公开往期回放列表接口`GET /api/v1/replays?roomCode=&tenantId=&page=&pageSize=`：分页返回该直播间已结束且`replay_enabled=true`的公开直播最小投影（标题、封面、开播日期、起止时间戳、`liveUrl`），按开播日期倒序、页大小有界（默认 10、上限 50）；租户语义与`play`一致；无内容返回空列表不泄露存在性。
  - 管理端直播内容列表响应新增`replayEnabled`字段；更新接口支持修改该字段。
- **管理端**：直播内容列表新增"回放"列，行内开关直接切换该场回放公开状态（调用既有更新接口），新建/编辑弹窗同步增加该开关；不新增页面与菜单（复用既有直播内容页，权限点不变）。
- **H5 观播页**：回放态信息面板下方新增"往期回放"区块，展示回放列表（封面缩略 + 标题 + 日期），点击任一场即切换播放器播放该场回放并更新标题徽标，当前播放场高亮；进行中/预告态不展示。
- 插件`apidoc`翻译资源同步新增回放列表接口的`zh-CN`翻译（插件`i18n.enabled: true`）。

## Capabilities

### New Capabilities

- `live-manage` 能力扩展：往期回放库（公开分页回放列表 + 每场回放开关 + H5 往期回放跳转观看）。

### Modified Capabilities

- `play`公开接口的已结束回退逻辑增加回放开关过滤（回放可见性收紧，属既定公开语义内的维护能力）。

## Impact

- **数据库**：插件迭代 SQL 新增一列（幂等）+ 卸载 SQL 同步；`make db.init`、`make dao`重新生成。
- **后端**：`play`回退过滤 + 新增`replays`列表查询（单条分页 SQL，无 N+1）+ 管理端字段透传。
- **前端**：H5 静态页新增回放区块（随`go:embed`重嵌）；管理端既有页面加一列一开关一表单项，不新增菜单权限。
- **测试**：`play`回退过滤单元测试、`replays`分页契约测试、E2E `TC007`覆盖开关生效性与 H5 跳转。
- **i18n**：新增接口`zh-CN` apidoc 翻译；H5 中文独立页、管理端文案按既有机制。
