## Context

书籍管理需求：书籍台账与借阅流转。核心是库存联动——借出扣减可借数量、归还回增，两者与借阅记录在同一事务内。

## Goal

1. `书籍登记`页：维护书籍台账（书名、作者、`ISBN`、分类、出版社、库存、可借数、位置、封面地址）。
2. `借阅记录`页：登记借出/归还，跟踪借阅状态与归还日期。

## 设计决策

- 表：书籍 `uk(tenant_id, isbn)`（`ISBN`允许为空字符串时不参与唯一约束——用部分唯一索引 `WHERE isbn <> ''`）；借阅表 `idx(tenant_id, book_id)`。
- 库存联动：借出事务内校验 `available_quantity > 0` 并扣减；归还回增；并发借出由 `UPDATE ... WHERE available_quantity > 0` 条件更新兜底。
- 状态机：借阅状态 `1=借出 2=已归还`；归还仅对`借出`记录允许且仅登记人可操作。
- 枚举字典：`plugin_book_category`（技术/文学/管理/童书/其他）、`plugin_book_borrow_status`（借出/已归还）。
- 封面以地址形式存储（与附件地址同语义，不上传文件）。
- 组织维度例外：借阅人为展示字段，不接入组织数据权限过滤，权威边界为租户隔离与权限点。

## Risks / Trade-offs

- 逾期判定不在 `v1`（列表按应还日期展示，人工判断）。
- 不做读者账户体系，借阅人自由文本。

## Migration Plan

安装幂等建表+字典 seed；卸载清理；`mock-data` 提供演示数据。
