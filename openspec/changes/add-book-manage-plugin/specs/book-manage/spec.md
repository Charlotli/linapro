## ADDED Requirements

### Requirement: 书籍台账租户隔离维护

系统 SHALL 在租户上下文中提供书籍台账的创建、分页查询、详情、更新与批量删除能力，字段覆盖书名、作者、`ISBN`、分类、出版社、出版日期、库存总数、可借数量、存放位置、状态、封面地址与备注。`ISBN`填写时 MUST 同租户唯一（部分唯一索引兜底）。删除仍被借阅记录引用的书籍 MUST 被拒绝。

#### Scenario: 登记书籍

- **WHEN** 具备`book:add`权限的用户提交书籍信息
- **THEN** 系统在当前租户下创建书籍并返回 ID
- **AND** 重复`ISBN`创建失败并返回唯一约束业务错误

#### Scenario: 删除被借阅记录引用的书籍被拒绝

- **WHEN** 用户删除仍存在借阅记录的书籍
- **THEN** 系统返回引用保护业务错误且不删除

### Requirement: 借阅库存事务联动

系统 SHALL 提供借出与归还能力：借出 MUST 校验书籍可借数量大于零，MUST 在事务内创建借阅记录（状态`借出`）并扣减可借数量；归还 MUST 仅对`借出`记录、由登记人执行，MUST 在事务内回增可借数量。可借数量 MUST 永不大于库存总数、不为负。

#### Scenario: 借出扣减库存

- **WHEN** 具备`borrow:add`权限的用户提交借出申请
- **THEN** 系统在事务内创建`借出`记录并扣减可借数量
- **AND** 可借数量为零时借出被拒绝

#### Scenario: 归还回增库存

- **WHEN** 登记人对`借出`记录执行归还
- **THEN** 系统在事务内置状态为`已归还`、记录归还日期并回增可借数量
- **AND** 重复归还或非登记人归还被拒绝

#### Scenario: 列表批量装配书名

- **WHEN** 用户查询借阅记录列表
- **THEN** 当前页的书名通过一次批量查询装配

### Requirement: 书籍枚举字典治理

系统 SHALL 通过字典模块维护`plugin_book_category`与`plugin_book_borrow_status`枚举标签；后端 MUST 使用命名常量，前端 MUST 通过字典渲染标签。

#### Scenario: 安装写入字典 seed

- **WHEN** 插件安装`SQL`执行
- **THEN** 两个书籍字典类型及枚举数据被幂等写入

### Requirement: 书籍管理菜单与权限点

系统 SHALL 声明书籍登记与借阅记录两个菜单（挂载宿主内容管理目录）及各自查询/新增/修改/删除按钮权限点，`API`权限标签与菜单一致；插件禁用后入口完全隐藏、数据保留。

#### Scenario: 菜单同步与权限校验

- **WHEN** 插件被安装启用
- **THEN** 宿主同步两个菜单页面与八个按钮权限点
